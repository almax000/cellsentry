## 部署顺序与回退

七附件、tag source、prerelease／latest=false 和匿名有界下载已核验。RC 标签不运行旧自动打包发布链。尝试部署既有 cellsentry-dl 时，Cloudflare 返回 No access to the specified service，未上传新脚本；私有 OAuth 存储实际仅 user:read／account:read／pages:write。此前 whoami 文本中出现 workers 权限名称不是有效 grant 的证明，不据它扩大权限。只读脚本列表返回空也不能证明 Worker 不存在，域名 API 返回 Authentication error。

本轮官网 DOWNLOAD_MAC 改为精确已发布 GitHub offline DMG 直链；Windows 保持现网稳定入口。以 Pages 生产部署及真实按钮为上线判据。`dl.cellsentry.pro/mac` 仍指向旧 beta.1，Worker 独立版本补丁保留供后续有明确部署权限时使用；当前没有把它称为已部署。部署和验证继续继承 HTTP/HTTPS 代理，不改变网络配置。后续最小权限依据 Cloudflare [Workers roles and permissions](https://developers.cloudflare.com/workers/authorization/workers/) 核对，并由用户确认任何新增授权。

官网需要回退时，将 DOWNLOAD_MAC 指向仍保留的已验证 RC.1 offline DMG；不要把旧 dl 路由当作 RC.3。未来 Worker 部署后可回退 MAC_OFFLINE_VERSION 至 RC.1，删除变量则回到 beta.1 legacy Mac DMG。稳定 Latest 与旧 Release 保留。不要 clobber 发布附件，任何二进制变化使用新版本。
