# ADR-0007：三个自调模型放在自有 CDN，App 内按需下载

- **Status**: Superseded by ADR-0015
- **Date**: 2026-10-18
- **Deciders**: jojo
- **Drafted by**: Claude Code · Opus 5.5（从 PRD 和当天的问答迁入）
- **Supersedes**: ROADMAP.md Decision Log 里 2026-03-15「HuggingFace model hosting」、2026-03-16「Download UX: full-screen blocking」、2026-03-17「ModelScope China download」三行（都没有迁成 ADR）
- **Superseded by**: ADR-0015
- **Legacy ID**: PRD D6、D3 追问
- **Related**: [PRD §3、§6、§10](../../.claude/product/PRD-v0-local-pii.md)、[可插拔端侧模型调研](../research/2026-10-18-pluggable-on-device-models.md)、[v2 分发核查](../evaluation/2026-10-17-v2-distribution-review.md)

## 背景

- **v1 的做法**：启动时全屏拦截，强制下载 986 MB 模型（2026-03-16 的决定），模型放在 HuggingFace，2026-03-17 起国内走 ModelScope。PRD §7 的漏斗里，这是最大的流失点之一。
- **v2 公式模型**现在挂在私有 GitHub Release 上，陌生人下载会 404。
- **D3 追问**（2026-10-18）：保留另两项的 AI 复核（[ADR-0004](0004-keep-all-three-features.md)）以后，1.56 GB 的大模型怎么交到用户手里？jojo 选了用户主动下载，并顺带提出一个设想：让用户自己从 Hugging Face 选模型、自动配置，把 CellSentry 做成可插拔的本地推理框架。
- **可插拔调研**（Codex，主会话抽查了 6 条）：“在 App 里选模型、自动下载、本地运行”已有大量产品（PocketPal、LM Studio、Ollama 等）。可插拔适合做成机制，不适合当主叙事；插拔的单位应该是“任务配置包 + 可信清单”，而不是单个模型。
- 看完调研，jojo 的原话：“自定义模型这个可以缓缓，当下就三大功能，对应我们自己调的三个模型就可以了，三个模型都挂在我们自己的 CDN 上，从 app 内提供下载。”

## 决定

- 三大功能各配一个我们自己调的模型，由 Black Sky 负责。
- 三个模型都放在 CellSentry 自己的 CDN 上，在 App 内下载。
- 用户第一次用到某项 AI 功能时，才提示下载对应的模型；不在启动时强制下载。规则部分装好就能用。
- 固定模型版本、校验 SHA256，下载完成后全程离线。对外承诺写成：“你的文件从不离开设备。只有下载模型时才联网，而且只连 CellSentry 自己的服务器。”
- 自定义模型和模型商店暂缓。产品以任务为导向、面向小白用户：由我们为每项任务挑最合适的模型。

## 考虑过的方案

| 方案 | 结果 | 理由 |
|---|---|---|
| 全部打进安装包（Mac 约 1.8 GB） | 否决（D3 追问） | 装完就完全离线，但不用公式审计的人也要下这么大的包 |
| 继续首次启动自动下载（v1 的做法） | 否决（D3 追问） | 做不到“装好就能离线用”，也是 v1 漏斗里最大的流失点之一 |
| 用户主动下载（D3 追问的推荐项） | 采用，后被本条细化 | 细化成：按任务、在第一次用到时提示，从自有 CDN 下载 |
| 用户自选模型，可插拔的本地推理框架（jojo 的设想） | 暂缓 | 这一层已有大量免费产品，重做拉不开差距；“任务配置包 + 可信清单”留到以后再用 |
| 继续用 HuggingFace / ModelScope 做下载源 | 不再作为对外的下载源 | 对外承诺要能写成“只连 CellSentry 自己的服务器”（PRD §6）。起草时补列，当天没有单独问 |

## 接受的代价

- 要自建 CDN。官网已经在 Cloudflare 上，R2 是最顺的选项，但费用和国内访问速度都没核实；如果要付费，需要 jojo 另外决定。
- 放弃了 HuggingFace / ModelScope 的免费分发，以及三月做好的国内选源。
- 用户第一次用某项 AI 功能时要等下载。
- 数据提取目前没有自己的模型，用的是模板加大模型兜底；第三个模型谁调、什么时候调，还没定。

## 后果

**好处**：

- “装好就能用、文件不出设备”能写成可以验证的承诺：发布前用断网和抓包各验一次（PRD §6）。
- 小白不用懂模型：每项任务只有一个由我们挑好的模型。

**风险**：

- jojo 已于本轮确认 v2 模型作者就是本人，不再存在等待第三方作者确认的阻塞；发行时仍须随包保留并核对 `LICENSE`、`NOTICE.txt`。
- CDN 的实际上传和部署仍需要 jojo 另外授权（PRD §10）；本仓目前只有 R2/Worker 的本地预备配置，未上传、未绑定、未部署。
- llama.cpp 的 GGUF 解析器出过高危漏洞（可插拔调研 P4）。固定版本、校验 SHA256、只开放可信清单能挡住大部分，但要持续跟踪安全公告。

## 重新评估的条件

- 发行包的许可证或 NOTICE 核对失败：v2 不能放上 CDN，要在“用公开的旧版 v3 兜底”和“公式审计先不带 AI 复核”之间选。
- 评估后 CDN 的费用或国内下载速度不可接受。
- 到 macOS 版公开发布时，第三个模型（数据提取）还没有负责人。

## 复盘（Q1–Q5）

不是复盘 ADR：被推翻的三条旧决定都在 30 天以前（2026-03）；当天的 D3 追问是被细化，不是被推翻，两者都是“用户主动下载”。
