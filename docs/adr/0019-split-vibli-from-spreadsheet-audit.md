# ADR-0019：CellSentry 聚焦表格审计，Vibli 独立承接 PII

- **Status**: Accepted
- **Date**: 2026-10-24
- **Deciders**: jojo
- **Drafted by**: Codex
- **Supersedes**: ADR-0002、ADR-0004、ADR-0008
- **Superseded by**: —
- **Legacy ID**: —
- **Related**: ADR-0011、ADR-0013、ADR-0014、ADR-0018

## 背景

jojo 在本轮产品讨论中明确同意拆分，并要求新建独立开发目录和交接：CellSentry 回到表格审计，Vibli 面向所有重视隐私的个人，承接敏感信息替换和外部 AI 回答还原。当前桌面 PII 实际使用本地规则，不调用公式模型，但历史 App 的首装/预热仍包含约 1.56 GB 公式模型。产品拆分可以使 PII 用户的首版无需下载该模型。

## 决定

CellSentry 只负责表格审计和相关处理，目标用户是财务、会计、小企业主。独立 PII 与独立发票字段抽取应从产品入口、自动执行、打包和文案移除，作为后续工程任务验证；本 ADR 的记录不代表代码拆分已经完成。

Vibli（vibli.app）提供导入→敏感实体/映射整理→人工复核并保存→选提示词模板/复制 Markdown→用户手动使用外部 AI→回到 App 粘贴→用保存映射恢复。首版不等待或接入模型。Black Sky 继续负责模型训练，jojo 负责其他产品环节；模型接口与合成评测可先准备。

Vibli 免费下载/试用后通过内购永久解锁，价格 US$19.99，手机和桌面分别打包。试用和跨平台购买细节未定。ADR-0010 的 CellSentry 免费开源决定没有在本次被改价；Vibli 的定价不应反向套用到 CellSentry。

两产品分别维护私有开发仓与公开发布边界，本地只常驻各自 Dev；公开代码按审查后的允许清单导出。既有的本地推理底线保留。外发 Markdown 是可读假名化文本，本地映射/项目另行加密，不承诺“绝对安全”或模型能分析密文。

## 考虑过的方案

|方案|结果|理由|
|---|---|---|
|继续三功能共用一个 App|由 jojo 否决|用户任务、模型体积、受众与商业化不同|
|CellSentry 审计，Vibli 脱敏/还原|由 jojo 采用|独立上手流程、模型分发、发布与官网|
|把信息抽取继续作为独立产品入口|未采用|敏感实体抽取保留为映射步骤，通用发票抽取不构成此次产品核心|

## 接受的代价

需要维护两个品牌、独立应用标识、安装/商店资料、官网和发行测试；平台适配不能仅把旧 Electron UI 复制到 iOS。旧功能的移除、映射持久化与历史用户升级也需要明确处理。

## 后果

Vibli 首版可围绕规则与人工完成闭环；CellSentry 模型与验证资源聚焦公式审计。现有已发布 RC.3 仍是历史三功能包，不能宣传为拆分已完成。旧医疗规则与评测是迁移输入，不把真实文档或训练数据直接带到新仓。

## 重新评估的条件

若真实用户任务显示必须在同一文件事务中联动审计与敏感替换，或独立发布维护造成可量化阻碍，再讨论集成入口；不能因共享少量代码就自动合并产品。未来 PII 模型需要提供足够召回增益、性能和许可证据再接入。

## 复盘（Q1–Q5）

### Q1. 上一版做对了什么（这次保留）

本地规则、人工复核、稳定代号和本机还原机制有效；端侧推理底线、合成测试和已知边界继续保留。

### Q2. 上一版做错了什么

把不同受众和模型需求的三项入口长期放在一包，令仅使用 PII 的用户承担公式模型体积；医疗聚焦也不代表新 Vibli 的完整市场。

### Q3. 为什么这次不是同一个坑

分别设仓库/打包/产品入口；Vibli 首版不初始化、预热、下载公式模型，持久映射版本成为分享前的必经步骤；CellSentry 的离线验收改为审计链路，不再依赖 PII 启动信号。

### Q4. 什么情况下回退

先验证两个完整独立闭环和用户升级方案；如出现前述必须同事务联动的实际任务证据，再提出新的 ADR，不静默恢复三功能 App。

### Q5. 遵守了哪些教训

用户决策与实现/安装包/隐私验收状态分别记录；残留为零不等于未知 PII 为零；公开仓只导出允许内容，不公开旧私有历史或模型/训练数据。
