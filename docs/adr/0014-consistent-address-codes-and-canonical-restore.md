# ADR-0014：地址保持一致代号，接受统一写法还原

## 背景

修复 PR #6 遗留的地址楼栋泄漏时，差分探针发现：将完整住址脱敏后，同址的不同表面写法会得到同一个代号。例如 `“文三路100号”3栋501室` 与 `“文三路100号” 3栋501室` 都成为 `地址1`。代码表为一个代号保存一个还原用的写法，不能从 AI 回答中的同一个代号判断原来采用了哪种空格、换行、引号或楼栋字母大小写。

另一个已存在的行为也适用于新增的完整地址：被识别为同一住址的街道副本可以共用完整住址的代号，因而会还原成完整住址。

## 决定

保留同址的一致代号。还原采用代码表为该代号记录的写法；一次生成中通常是首次出现的写法，不承诺每个位置逐字恢复原始排版，也不承诺街道副本仍只还原街道。

jojo 在本次接手续修中明确选择了“保留一致代号，接受并记录还原限制”。正常成对引号的脱敏不应留下孤立开引号，单独还原一个代号也不应凭空多出闭引号；这两项仍由回归测试约束。

## 考虑过的方案

| 方案 | 结果 | 理由 |
|---|---|---|
| **一致代号，统一写法还原** | **采用** | 保持跨报告比较的语义，完整遮住楼栋房号 |
| 按每种原始写法分配不同代号 | 否决 | 同一住址会出现多个代号，削弱一致假名化 |

以上两项是本次直接询问 jojo 的选项。另有按出现位置保存原文元数据的实现方向，本次未选择，也未实施。

## 接受的代价

- 原文中同址的空格、换行、引号和字母大小写差异可能消失。
- 与完整住址共用代号的街道副本可能被还原为完整住址。

## 后果

同一住址仍能在不同报告中对齐；新增楼栋房号不再因保留排版而漏出。还原结果应被理解为代码表中的个人信息写法，不能当作原始文档的逐字重建。

## 重新评估的条件

- jojo 或真实用户需要把还原结果作为逐字复原的原始文档使用。
- 一致代号对应的统一写法改变了住址含义，而不仅是排版或地址粒度。

## 复盘（Q1–Q5）

不是复盘 ADR：保留 ADR-0002 的一致假名化方向，明确本次已验证并由 jojo 接受的还原边界，没有推翻既有决定。
