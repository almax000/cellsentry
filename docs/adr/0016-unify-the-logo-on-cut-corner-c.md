# ADR-0016：统一采用等厚切角 C（方案 A）

## 背景

安装包、应用内、官网与 Excel 插件此前使用不同的 C、颜色和盾牌标记。jojo 在查看原版 Figma 设计及随后的一组九个原生 SVG 方案后，明确确认：“A好，logo统一替换为A吧”。本记录落实这条已给出的决定。

## 决定

采用等厚切角 C（A），保留原版的方格骨架、切角与右侧斜开口。单一母版为 `app/resources/brand/mark.svg`，viewBox 为 `0 0 256 256`。选定路径为：

```text
M224 80L176 128V80H80V176H176V160L224 112V176L176 224H32V80L80 32H224Z
```

标志统一黑白。已有 UI 品牌绿、功能图标、字体与页面布局沿用现状。由同一个母版生成应用组件、平台图标、官网/favicon、公开同步覆盖与插件品牌图标；源和生成命令见 BRAND.md。

## 考虑过的方案

| 方案 | 结果 | 理由 |
|---|---|---|
| **等厚切角 C（A）** | **采用** | jojo 明确选择；保留原设计的主要轮廓 |
| 较细或微圆角 C（B、C） | 未采用 | 同轮提供的几何对照，jojo 选择 A |
| C 融合锁孔、盾形（D–I） | 未采用 | 同轮提供的语义增强对照，jojo 选择 A |
| 厚墙 C 加代号条 | 未采用 | 前轮设计建议；本次选定的 A 不含代号条 |

这些是同一设计探索中实际提供的选项，不是代理评分证明的优劣排序。

## 接受的代价

字母 C 本身不会完整解释离线推理或医疗脱敏；产品文案与交互承担这些说明。原版的立体切面被移除。平台需要透明圆角的桌面图标与不含透明通道的 iOS 方形图标两种导出，几何仍来自同一个母版。

## 后果

**好处**：活跃品牌入口使用同一轮廓；生成命令及检查命令能发现派生资产漂移。

**风险**：尚未经过真人盲读或商标图形检索；传统 C 字标可能与其他产品相似。替换源资产不等于已经重新发布安装包或完成官网部署。

## 重新评估的条件

在真实平台出现辨识或裁切问题时，先调整对应尺寸的留白与渲染；修改母版轮廓须由 jojo 再次确认。遇到明确的品牌混淆证据或权利冲突时重新评估。

## 复盘（Q1–Q5）

不是复盘 ADR：此前没有已接受的新 logo ADR；本次是记录 jojo 对设计探索结果的正式选择。
