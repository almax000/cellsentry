# CellSentry 与 MiniCPM5-2B 同用例复测

基线：cellsentry-1.5b-v3；复测：MiniCPM5-2B-Q4_K_M。两者均为 Q4_K_M。

500 个用例、系统/用户消息、评分函数保持一致；temperature=0，seed=42，输出上限 420 token，上下文 1024，llama.cpp 构建相同，单请求串行。
MiniCPM 使用原生 Jinja 聊天模板并设置 enable_thinking=false；模型专属分词器和模板不同，因此 token 数不同。未使用额外任务微调、JSON grammar 或答案修复。

|敏感信息|160|39/160 (24.4%)|64/160 (40.0%)|+15.6 个百分点|

严格通过要求有效 JSON、完整字段协议、答案及来源地址完全匹配。公式输出把 D5 改成 Sheet1!D5 也会失败，因为应用按原地址匹配；所以另外列出真假判断分数。

这是同一组合成覆盖样本上的局部比较。每类包含相关模板变体、金标准未经独立人工审核，不能当作通用模型排名或生产准确率。未测试 Excel 文件解析、规则引擎和 UI，也未测试 MiniCPM 默认思考模式或更大上下文/输出预算。
