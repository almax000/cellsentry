## 回归与后续

跨作者 F1 提升到 90.18%，旧复杂诊断提升到 74.81%，表明自由表达目标与段落比继续增加固定模板更有效。与此同时，旧模板误保留增加到 426 段，复杂诊断仍有 26 段误保留；不能以召回改善替代精度审核。

下一轮应针对“目标明确排除历史/撤销/示例，但当前段含这些关键词”的否定范围与排除条件生成独立反例，增加同段目标正负反转和相同含义不同措辞的一致性样本。先冻结新训练/验证来源，不把现有失败测试句子加入训练，也不在这些测试上重新调阈值。

## 边界

模型一致标注仍可能共同出错，不能替代人工审核；一致性筛选也可能偏向简单样本并保留共同偏差。新测试只在权重与阈值冻结后评分；旧测试未进入训练/验证。当前权重仅本地实验，尚未转换 GGUF、接入 App 或测量手机性能。

训练目标和段落由模型自由撰写，不把旧失败测试句子加入提示词或训练。原始响应与分歧样本隔离，记录各提供方、请求摘要、用量和文件 SHA256。
