## 评测边界

旧测试 8320 对、旧诊断 192 对均保留为已知回归集，未取内容或标签加入训练/开发。新测试在训练开始前冻结，未调阈值或选权重。所有数据均为本地合成，仍需独立来源的脱敏真实文件验证。

数值条件同时覆盖严格大于/小于、等于阈值、包含边界的区间。未在推理阶段添加数值规则或后处理；成绩来自 mmBERT 二分类自身。

## 原因与后续方向

v1 在新测试集全部拒绝，v2 在新模板上高分、却在旧测试与不同措辞诊断上回退，说明两个版本都依赖训练输入的表述。扩大相同生成逻辑的样本数不足以证明目标理解能力。

v2 在新开发集的历史目标 F1 很高，但旧诊断中的历史与数值筛选仍无法召回；这也说明开发集未覆盖足够多的自然语言表达。当前开发指标不应作为单独发布标准。

下一轮应采用独立多来源作者生成目标和段落、跨作者复核标签，将目标措辞、事实表述、条件表达分别改写，并加入同义目标一致性与同段目标反转对照。保留现有测试为回归集，不把失败测试题转入训练；另外冻结新的独立测试集。

当前仅本地 FP32 实验权重；没有上传、量化、修改现有 App 或发布 TestFlight。
