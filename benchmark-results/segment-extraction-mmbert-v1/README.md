## 局限

这是合成数据工程验证，不代表任意用户目标、未知业务或真实文件准确率。文档、数值和外层呈现模板隔离，但业务事实句式及目标改写仍共享。尚未转换 GGUF、接入产品或测量手机性能。

输入超过 512 token、推理失败或取消应返回显式错误，不能作为“不命中”。离线推理脚本按段报告状态；输出不拼接或改写原文。

下一轮应先冻结独立来源的自然语言目标与真实脱敏段落，覆盖排除条件、混合主题、否定、数值筛选和长段；确认泛化后再量化及部署。

## 错误与下一步

模板测试 37 次误保留均来自“演练材料”模板，没有漏段。诊断集则是 38 次漏段、没有误保留；历史目标和数值条件均未命中。

训练目标始终限定“当前有效”，并把历史记录作为负例，因此模型没有学到“同一段可随时间范围目标改变而变成正例”；数值条件也没有训练覆盖。这是本轮数据设计的覆盖缺口，不能仅靠降低阈值解决，也不能据此认定 mmBERT 的能力上限。

后续应从独立来源补充多种目标条件的训练与验证数据，同时重写同段正负反转样本；保留本次测试与诊断集为回归集，再建立未看过的新测试集。不得把这批测试题转入训练。
