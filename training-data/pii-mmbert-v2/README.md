# PII mmBERT v2 独立训练/开发资料

训练为1,120份新合成文档与原v1的720份训练文档，共1,840份。开发为独立生成的160份；开发正例值与训练正例值无完全相同项。原360份测试仅作回归推理。

新合成数据覆盖字段、TSV键值对、TSV行表格、空格表格、脱离表头、引号值、混合字段与临床短句；同样格式的字符串分别出现在患者/家属与医生、公共机构、订单、教学代码字段，训练8类判定。

生成脚本不读取64份ARK挑战集、其中的原文、标签或预测。生成器仅读取原冻结dev/test以检查正例值交叉；测试标签只用于离线计分。64份挑战集仅在版本冻结后用于已见回归测试，不能据此宣称独立盲测泛化。

这是有限模板合成实验，不是人工真实医疗语料。v2候选与短上下文输入对应单独权重，不能混用v1输入。文件SHA256、标签分布、生成器源哈希见manifest.json。检查点仍为本机实验safetensors，未转换GGUF、未接入App或手机。
