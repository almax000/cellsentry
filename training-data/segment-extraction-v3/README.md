# 多作者自然语言分段提取 v3

保持“目标＋当前段 → 保留/丢弃”的二分类契约，命中后逐字保留整段、顺序及来源；不输出子字符串或字段。超过 512 token 显式报错。

本轮训练与开发材料由 Doubao Seed 2.1 Lite、DeepSeek V4.1 Flash 写作并交叉独立标注；GLM 5.3 写作测试文档，由 Doubao 独立标注。只有整份文档的全部目标标签完全一致才接受，其余隔离。早期未采用的 GLM 复核响应不进入训练或开发语料。

- 自然语言训练：150 文档 / 2400 对，658 个保留标签。
- 自然语言开发：37 文档 / 592 对。
- 跨作者测试：53 文档 / 848 对，224 个保留标签。
- 隔离：92 文档。
- API 记录：129 次已记录调用，255635 token，包含早期未采用复核。

训练池另取 v1/v2 的 **train** 各 4000 对，开发集另取 v1/v2 的 **dev** 各 1000 对。v2 回放只取其新生成文档，排除重复 v1 回放。总训练池 10400 对，开发 2592 对。旧测试、旧 192 对诊断、旧 PII 64 份材料完全不进入 train/dev。

自然语言目标自由表达，包括当前/历史、所有时期、数值条件、撤销、计划、人员角色、主题与组合条件；文风与段落由作者自由生成，未提供旧测试原文。按文档隔离，精确重复与作者身份在训练前校验。训练和开发作者集合不含测试作者，开发和测试的条件分布不完全相同，详见 manifest.json 的 scopes。

从 extraction v2 选定权重继续全参数训练 1500 步，学习率 5e-6、有效批量 16、BF16 autocast。带放回抽样约 80% 来自自然语言训练，20% 来自回放，共 24000 次抽取。按开发集“80% 自然语言目标宏平均 F1 + 20% 回放目标宏平均 F1”选 checkpoint/阈值，最终测试不参与选择。

Python 只用于离线训练/评测，不进入产品依赖。当前权重独立于公式和 PII 编码器，没有共享或修改它们。

恢复冻结 JSONL 并运行检查：

```powershell
python scripts/archive_segment_dataset.py --data training-data/segment-extraction-v3 --restore
python scripts/test_segment_extraction_v3.py
python scripts/train_segment_mmbert_v3.py --eval-every 300
```

复现训练还需本地 v2 best 权重和原始 mmBERT source manifest；重复运行请指定新的 `--output`。新一轮生成必须使用新的目录与版本号，不能覆盖这些冻结文件。

本轮使用用户先前提供的方舟 Key；脚本从 WSL 指定文件读取，不保存到仓库或日志。不向 API 发送项目内容或既有测试原文；原始响应和分歧材料保留在本地 `.runtime/segment-ark-v3`，不进入聊天上下文。

跨模型一致可能保留共同偏差，且一致性筛选可能偏向简单样本，因此这些标签不能视为人工金标准或真实业务准确率。测试规模有限，角色和全部时期等条件样本较少，需结合按 scope 的分数与样本量判断。独立真实脱敏文件审核仍是上线前必要的验证。

评测包含同一批跨作者测试上的 v1/v2/v3，以及三个原有回归集。报告位于 `benchmark-results/segment-extraction-mmbert-v3/README.md`。本轮未量化、上传模型或修改 App。
