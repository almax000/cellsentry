# 分段提取 v4：否定范围与排除条件

新增语料专门处理目标排除历史、撤销、计划、示例时的误保留，以及含否定词但实际仍有效的反例。当前段始终完整保留或丢弃，不做长字符串生成或子串定位。

每份新文档有四段、四个自然语言目标。两个目标选择当前有效记录、另外两个选择其中一类排除项；每组两条目标是同义改写，两组应命中的段落集合非空且互斥。目标顺序不固定。生成者与另一模型独立标签须全部一致，且通过目标反转与同义集合检查，才整份接受。

训练/开发由 Doubao 与 DeepSeek 写作并交叉复核；GLM 只写新测试材料，由 Doubao 复核。早期响应格式和排列问题通过缓存重放处理，没有改变标注语义。

- 新重点训练：99 文档 / 1584 对。
- 新重点开发：27 文档 / 432 对。
- 新重点测试：48 文档 / 768 对。
- 隔离：65 文档。
- 记录调用：103 次，208880 token。

训练池同时保留原 v3 train：2400 对通用自然语言 + 8000 对旧训练回放，合计 11984 对。开发合计 3024 对。所有旧测试、192 对诊断和 PII 64 份测试材料均未进入 train/dev，未放入生成提示词。精确输入与旧测试重叠检查已通过。

从 v3 选定的 step1200 权重继续全参数训练 1200 步，学习率 3e-6，负类损失权重 1.5，BF16 autocast，有效批量 16。带放回抽样：40% 重点 / 40% 通用自然语言 / 20% 回放，共 19200 次样本抽取。

开发集选权重/阈值时使用同样 40/40/20 加权的 F0.5，优先精度，同时要求重点与通用自然语言两部分召回均达到 85%。未达门槛的候选得分加惩罚并标记失败；不能靠全部拒绝赢得选择，任何通过门槛的候选优先于失败者。最终测试不参与阈值选择。报告还比较 v3 权重不变、仅按本轮开发标准重新选择阈值的对照，区分策略和权重效果。

恢复与训练：

```powershell
python scripts/archive_segment_dataset.py --data training-data/segment-extraction-v4 --restore
python scripts/test_segment_extraction_v4.py
python scripts/train_segment_mmbert_v4.py --eval-every 300
```

需本地 v3 best 和原始 mmBERT source manifest。重复训练请用新的 `--output`，不得覆盖冻结记录。Python 仅离线训练/评测使用，产品没有新增 Python 依赖。

评测包含新重点集、原 GLM 跨作者通用集、原两套模板集和 192 对诊断。同义一致率不等于正确率，两条目标可以共同判断错误，应结合 P/R 和整组准确率。全部数据为模型生成并经另一模型一致标注，仍可能有共同偏差；一致性筛选也可能偏向简单样本，不能视为人工金标准或真实用户准确率。

模型未量化、上传或接入 App；结果见 `benchmark-results/segment-extraction-mmbert-v4/README.md`。
